# PPE Detection
This repository demonstrates object detection using the YOLOv8 model for detecting  personal protective equipment (PPE) such as helmet, gloves, goggles, jacket, and footwear. The project has the conversion of dataset annotations in YOLO format and the implementation of the YOLOv8 model for object detection.
## Overview
This project aims to detect  various PPE items using a custom-trained YOLOv8 model. It includes: 
- Training a YOLOv8 model on a custom dataset.
- Making predictions and visualizing the results with bounding boxes.
